*A 3.1 GEN 1 USB HUB with 4 USB3 female output featuring VL182. This hub is self powered hub & and each USB power pin has flyback protection. Personal reason for this board is to use it with my laptop because it only has one USB3.1 output.*

# Hardware 

  - **USB3.0 Hub chip :** VL812
  - **Four Led for indicating port usage** 
  - **On chip voltage regulator for 3V3 & 1V2** 
  - **Flyback Power protection on each Port**
